# src/hooks

## Finalidade

Hooks compartilhados do frontend para encapsular comportamento de interface, estado e acesso a capacidades reutilizáveis.

## Regra

Um hook deve representar uma responsabilidade reutilizável. Regras de negócio extensas, segurança, persistência e inteligência não devem ser escondidas em hooks de tela; devem permanecer nas camadas apropriadas de serviço, Core ou EIOS.

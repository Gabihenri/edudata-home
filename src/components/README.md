# src/components

## Finalidade

Biblioteca de componentes da EduData IA. Reúne elementos reutilizáveis da Home, produtos, navegação e experiências internas.

## Regra de reutilização

Antes de criar um novo componente, verificar se já existe uma solução equivalente. O objetivo é evoluir gradualmente para um Design System único, mantendo consistência visual e reduzindo duplicação.

## Organização esperada

Os subdiretórios agrupam componentes por domínio ou produto, sem criar bibliotecas isoladas quando uma capacidade puder ser compartilhada por toda a plataforma.

# EIOS Context

Este domínio concentra capacidades relacionadas à composição e ao uso de contexto pelo EIOS. Seu objetivo é fornecer aos serviços inteligentes informações estruturadas sobre usuários, instituições, produtos, situações e outros elementos necessários para respostas e decisões contextualizadas.

## Responsabilidade

Contexto é uma capacidade transversal do sistema operacional de inteligência. Por isso, não deve ser duplicado dentro de cada produto. Produtos fornecem os dados permitidos e consomem resultados por meio de contratos e serviços compartilhados.

## Regra de integração

A evolução deste domínio deve preservar isolamento entre tenants, permissões e privacidade. Contextos utilizados por operações inteligentes devem respeitar as regras do Core Compartilhado antes de serem disponibilizados ao EIOS.

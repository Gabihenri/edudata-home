# EIOS Evidence Intelligence

Este domínio concentra capacidades do EIOS relacionadas à interpretação, organização e uso de evidências educacionais como base para inteligência e apoio à decisão.

## Papel no Framework EDI

A existência deste domínio materializa tecnologicamente o princípio de **Evidências** do Framework EDI, sem transformar o Framework em código. O Framework orienta a metodologia; o EIOS implementa capacidades reutilizáveis compatíveis com essa metodologia.

## Integração com produtos

Produtos podem registrar ou disponibilizar evidências dentro de seus fluxos específicos. A lógica compartilhada de análise e geração de inteligência deve permanecer centralizada aqui ou em outros domínios do EIOS, evitando implementações paralelas por produto.

## Governança

Toda evolução deve respeitar identidade, permissões, contexto institucional e regras de proteção de dados antes de qualquer processamento inteligente.
